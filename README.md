# Цифровая экосистема «Родныя»
### Единая платформа поддержки материнства, детства и семьи в Республике Беларусь

**Проект:** «Родныя»  
**Конкурс:** Республиканский молодежный проект «100 идей для Беларуси — 2027»  
**Тип продукта:** Адаптивный веб-портал + Устанавливаемое мобильное PWA-приложение  

---

## 🌿 1. О концепции проекта

«Родныя» — это современная национальная цифровая экосистема, которая объединяет государственную социальную поддержку семей, медицинскую информацию, психологическую помощь, карту детских учреждений и защищённое хранилище документов в едином удобном окне.

Платформа сопровождает человека на всех этапах семейной траектории:
1. **Планирование беременности** (медицинские чек-листы, анализы, приём фолиевой кислоты).
2. **Ведение беременности** (календарь по неделям, скрининги Минздрава РБ, расчёт декретного отпуска).
3. **Рождение ребёнка** (единовременные выплаты 10–14 БПМ, ЗАГС, служба «Одно окно»).
4. **Пособия по уходу до 3 лет** (35–40% СЗП, семейный капитал 31 426 BYN, льготы на питание).
5. **Социальная инфраструктура** (интерактивная карта детсадов со свободными местами, поликлиники, пандусы, комнаты матери и ребёнка).
6. **Кризисная и психологическая поддержка** («Семейный щит», кнопка SOS, горячие линии Беларуси, онлайн-медиация для пар).
7. **Умный помощник «Родныя»** (интеллектуальный консультант по законодательству Беларуси).

- **Компьютерный портал (Desktop):** просторная шапка с выбором региона Беларуси, развёрнутыми меню, широкими карточками, интерактивными графиками и боковыми панелями.

## 🛠️ 3. Технологический стек

### Frontend
- **Next.js 14 (App Router)** — высокопроизводительный серверный и клиентский рендеринг.
- **React 18 & TypeScript** — строгая типизация всех данных и компонентов.
- **Tailwind CSS** — атомарная дизайн-система и палитра «Родныя».
- **Lucide Icons** — векторная иконографика.
- **Framer Motion** — анимации переходов и карточек.
- **Recharts** — интерактивные графики аналитики в панели администратора.
- **Leaflet & OpenStreetMap** — картографический модуль детсадов и доступной среды.

### Backend & Database
- **Supabase PostgreSQL** — реляционная база данных (26+ таблиц).
- **Row Level Security (RLS)** — разделение прав доступа (личные данные, медицинские записи, публичные статьи).
- **In-Memory & LocalStorage Client Fallback** — автономная работа без обязательной настройки внешнего сервера.

### PWA (Progressive Web Application)
- **Web App Manifest (`public/manifest.json`)** — установка на экран Android и iOS.
- **Service Worker (`public/sw.js`)** — кеширование ресурсов и работа офлайн.
- **Страница автономного режима (`/offline`)** — доступ к номерам экстренной помощи без интернета.

## 🗄️ 5. Настройка базы данных Supabase

Полная структура базы данных и начальные данные подготовлены в папке `supabase/`:

1. **SQL-миграция структуры:** `supabase/migrations/20261031_init_rodnya.sql`
   - Создаёт 26+ таблиц (`profiles`, `children`, `family_members`, `benefits`, `institutions`, `specialists`, `documents`, `checklists`, `user_events`, `conversations`, `messages`, `moderation_requests`, `audit_logs` и др.).
   - Настраивает Row Level Security (RLS) политики.
2. **Начальные данные (SEED):** `supabase/seed.sql`
   - Реальные нормативы пособий Республики Беларусь (БПМ, СЗП, семейный капитал).
   - Детские сады и поликлиники Минска, Гродно, Бреста.
   - Проверенные психологи, педиатры и медиаторы.
   - Чек-листы и статьи.

### Подключение внешнего проекта Supabase (опционально)
Создайте файл `.env.local` в корне проекта:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

> **Примечание:** Если ключи не указаны, приложение автоматически работает в **автономном демонстрационном режиме**, сохраняя добавленные документы, детей, события и расчёты в браузере!

## 📋 7. Статус реализации функционала (по ТЗ)

### ✅ Полностью реализовано и готово к демонстрации:
1. **Компьютерная версия портала** — широкая навигация, первый экран «Вместе для счастливого детства», декоративные элементы, модуль «Семейный маршрут», статистика Беларуси, каталог учреждений.
2. **Мобильная версия (PWA-приложение)** — компактная шапка со статусом, фиксированная нижняя панель (5 пунктов), карточки быстрых действий, баннеры «Мои выплаты» и «SOS-поддержка 24/7».
3. **Навигатор льгот и субсидий (`/benefits`)** — калькулятор пособий по актуальным нормам РБ (БПМ 437.80 BYN, СЗП 2 415.70 BYN, 1-й/2-й/3-й ребенок, пособия до 3 лет, семейный капитал 31 426 BYN, льготы на питание в садах), интерактивный чек-лист «Декрет без бюрократии» с сохранением прогресса.
4. **Семейный щит (`/psychology`)** — заметная кнопка SOS, модальное окно с проверенными горячими линиями РБ (8-801-100-8801, 8-801-100-1611, кризисные комнаты ТЦСОН), онлайн-медиация для пар (3 пошаговых упражнения), каталог психологов и форма записи.
5. **Здоровое поколение (`/health`)** — календарь беременности по неделям (расчёт от даты LMP, триместры, сравнение плода с фруктами, вес, длина, клинические протоколы Минздрава РБ), чек-лист подготовки, форма вопроса врачу-педиатру.
6. **Социальный гид (`/infrastructure`)** — интерактивная карта Leaflet + OpenStreetMap с метками учреждений в Минске, Бресте и Гродно, фильтры по доступности для колясок, отображение свободных мест в детсадах («Есть места»), форма добавления объектов доступной среды.
7. **Модуль «Уже родители» (`/family`)** — добавление профилей детей с возрастом и заметками, семейный календарь вакцинации и плановых осмотров, руководства по возрастам (0–1 год, 1–3 года, 3–6 лет, 6–12 лет).
8. **Цифровая папка «Мои документы» (`/documents`)** — защищённое хранилище (свидетельства о рождении, справки, паспорта), загрузка, фильтрация по статусам («Проверено», «В обработке»).
9. **Умный помощник «Родныя» (`/assistant`)** — чат-ассистент, обученный на нормах белорусского семейного законодательства, быстрые подсказки, ссылки на официальные ведомства.
10. **Центр уведомлений (`/notifications`)** — счётчик непрочитанных, категории, отметки о прочтении.
11. **Система диалогов (`/chats`)** — переписка со специалистами в реальном времени с автоматическими ответами.
12. **Личный кабинет (`/dashboard`)** — единая сводка семьи, документов, событий и прогресса.
13. **Административная панель (`/admin`)** — графики Recharts, редактирование размеров пособий, добавление учреждений, очередь модерации пользовательских предложений, журнал аудита.
14. **PWA-модуль** — манифест, иконки, Service Worker, страница автономного режима `/offline`.
